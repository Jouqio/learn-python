# Exercises

Every numbered topic file already contains its own EASY/MEDIUM/CHALLENGE
exercises inline (see the "3. PRACTICE" section of each file). This folder
holds **additional standalone practice sets**, organized by difficulty, for
extra reinforcement once you've completed a group of topics.

- `beginner/` - fundamentals, data structures, control flow
- `intermediate/` - functions, OOP, file handling
- `advanced/` - libraries, database, machine learning

Solutions live in `solutions/`, mirroring these file names. Try each
exercise yourself before checking the solution.
